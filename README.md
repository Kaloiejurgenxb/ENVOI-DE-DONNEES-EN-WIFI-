# TP : Envoi de données en WiFi avec ESP32

Objectif du TP
Comprendre comment un ESP32 peut :
- lire une donnée (capteur ou valeur simulée)
- se connecter à un réseau WiFi
- envoyer cette donnée à un serveur Ubuntu via HTTP POST
- enregistrer la donnée dans un fichier texte et CSV
- afficher la dernière valeur reçue sur une page web dynamique

Contenu du dépôt

/TP
Contient le fichier Word du TP.

/code
Contient les fichiers utilisés dans le TP :
- esp32_post.ino
- data.php
- index.php

Technologies utilisées
- ESP32
- Arduino IDE
- Apache2 / Ubuntu
- PHP
- HTTP POST
- CSV / TXT
